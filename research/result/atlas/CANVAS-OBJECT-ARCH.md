此前"48 虚表"清单缺这些 4 字节间距的子虚表——现在补齐为**虚表组**。

## 绑定链（全静态闭环）

```
exe: PcCreateObject(L"Canvas") 
  → Canvas.dll!DllGetClassObject: wcscmp(rclsid, L"Canvas"@0x5002C2B4)
  → 描述符 0x5002C248 {IID 表 0x5002C2E0, 生命周期 0x500058B0}
  → 构造器（vt=0x500272B8 / 0x50027364 / 三重组）→ 单例 AddRef
```

## 结论

上轮发现的"名字类标识"本轮闭合到虚表级。剩余：方法级语义
（构造器调用点 → exe 侧使用哪个接口的哪些方法 → 精读方法体）。
全部静态可行。
