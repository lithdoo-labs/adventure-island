# DLL 虚表静态图谱（重大突破）

日期: 2026-11-12。此前被标记为"需运行时数据、静态不可达"的 DLL 虚表分派层，
通过对磁盘上 5 个原始 DLL 的 .rdata 静态扫描**完全提取**。

## 突破方法

虚表布局编译时固化在 .rdata：连续 ≥4 个指向 .text 的指针 = 虚表。
不需要运行时转储。

```
.work/task-001/extracted/冒险岛online/{Gr2D_DX8,Canvas,Shape2D,NameSpace,ResMan}.dll
  → PE 解析（.text/.rdata 区段 + ImageBase）
  → .rdata 扫描指针数组 → 48 个虚表 / 2,219 方法槽
  → 方法 RVA + ImageBase - 0x400000 = 反编译 CSV 键（约定 A 验证: 1083 命中 vs B: 0）
```

## 关键结构解读

### Gr2D@0x2e2c4 (151 槽) — 抽象基接口
- 槽 0-4: 有实现（179/393/0/0/1035 字符）
- 槽 5-40+: 全部指向同一桩 0x2a610 = 纯虚占位
- 性质: PCOM 基接口定义（QueryInterface/AddRef/Release 在 0-2）

### Gr2D@0x2f2cc (132 槽) — 图元绘制分派表 ⭐
- **完美 4 方法重复组 × 33 组**: (TRIVIAL 179c, MATH ~900c, MATH ~1300c, 共同 1062c)
- 解读: 33 种绘制图元 × 4 操作（查询/验证/变换/公共提交）
- 第 4 槽恒为 0x19056 (1062c) = 公共提交处理

### Canvas@0x285e0 (124 槽) — 属性对象
- 78 个 173 字符微方法 = getter/setter 对
- 槽 20 (Canvas@0x270e8) = 8913 字符大方法 = WZ 反序列化/位图解码核心

### NameSpace@0x17548 (124 槽) — WZ 命名空间接口
- 槽 7 (5879c) = 路径解析核心；槽 8 (2030c)、槽 9 (3723c) = 子节点枚举
- 槽 13, 17-27: 间隔 0xA 的微桩家族 = 属性类型 getter（返回类型标签）

### NameSpace@0x18a54 (124 槽) — 第二命名空间接口
- 槽 12-19: 1274-2349 字符 MATH 组 = 数据变换家族

### ResMan@0x70d0 (45 槽) — 资源管理器
- 槽 7 = 11,183 字符 = 资源加载器核心（最大单方法）
- 槽 30-39 完全重复槽 0-9 布局 = 接口继承（两接口共享实现）

## exe→DLL 调用闭环

- exe 内 **8,440 个接口调用点**提取（EXE-IFACE-CALLSITES.csv）
- 槽位直方图: idx=2 × 3,617（COM Release!）、idx=32 × 829、idx=36 × 451
- idx 上限 71 与 80+ 槽接口吻合 = 调用确实走这些虚表
- 342 个接口变量组 × 候选虚表映射（IFACE-VARIABLE-RESOLUTION.csv）
- 8,444 行调用点→候选方法表（EXE-DISPATCH-RESOLVED.csv）

**注**: 栈变量名分组（piVar1 等）是 Ghidra 命名，跨函数不区分接口，
故为"候选映射"而非逐点确定绑定。确定绑定仍需运行时或数据流追踪。
