# Gr2D 像素格式引擎破译（第十三轮）

日期: 2026-11-12。132 槽分派表精读（此前误判为"33 图元绘制分派"）。

## 修正结论：132 槽 = 33 条像素格式转换管线 × 4 方法

### 每组 4 方法结构（指令级证实）
| 槽 | 方法 | 身份 |
|---|---|---|
| m0 | ~179c | 析构/调整器（thunk + 条件释放） |
| m1 | 700-1200c | **解码器**：源格式 → 浮点 RGBA |
| m2 | 900-1550c | **抖动量化器**：浮点 RGBA → 目标格式（4×4 有序抖动，按屏幕坐标 mod 4 索引） |
| m3 | 1062c 固定 | **公共锁面包装**：状态保存 → 接口调用对（Lock/Unlock）→ 恢复 |

### 已确认格式（前 9 组掩码级证据）
| 组 | 掩码/移位 | 格式 |
|---|---|---|
| 0/1 | 0x7C00/0x03E0/0x1F >>10,5 | **RGB555** |
| 2 | >>4,0 + 字节读 | **4 位调色板** |
| 3/5 | >>5,2 字节指针 | 低位深字节格式（2 位调色板族） |
| 4 | 无移位字节指针 | 8 位调色板/灰度 |
| 6 | >>4 | 4 位族 |
| 7 | 0x3FF × 3 | **RGB101010（30 位深彩）** |
| 8 | 0xFFFF | **16 位单通道（灰度/亮度/alpha）** |

### 解码器样例（组 0，指令级）
```c
R = ((pix & 0x7C00) >> 10) * scale;
G = ((pix & 0x03E0) >> 5)  * scale;
B =  (pix & 0x001F)        * scale;
A = 1.0;                    // 浮点 RGBA 四元组输出
```
### 抖动量化器样例（组 0）
```c
d = ditherTable[(y&3) + (x&3)*8];        // 4×4 有序抖动
out = (ROUND(r*max+d)<<5 | ROUND(g*max+d)<<5) | ROUND(b*max+d);  // → 555
```

## 架构意义

- Gr2D = **CPU 侧像素转换引擎**（软件路径）+ D3D8（硬件路径）双轨
- 33 格式管线覆盖：555/565/888/调色板 2/4/8 位/101010/16 位单通道等
- 对开发者：WZ 贴图格式 → 统一浮点 RGBA 中间表示 → 目标表面格式，
  抖动参数 = 4×4 有序抖动矩阵（索引 = 屏幕坐标 mod 4）
