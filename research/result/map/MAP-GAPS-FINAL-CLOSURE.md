## 爬绳

### A 级（指令记录）

**抓取查询**（`0xA4FC6F` 查询函数 + `0x9D7E9F` 调用方）：
- `0xA4FC6F` 把两个 x 参数排成低到高，低端再减 10、高端加 10；y 参数只排序
- `0x9D7E9F` 用人物 x 当两端、y 和 y-20 去查 → **水平各 10、竖直 20 的命中框**
- 命中条件：x 低界 `<=` 记录 `+0xC` `<=` x 高界（且 y 条件）

**命中处理**（`0x9D7D5A`）：
- 竖直速度对 `+0x68/+0x78` 写 0
- 水平速度对 `+0x50/+0x60` 写 0
- 人物 x（`+0x20` 成对双精度）= 记录 `+0xC`（吸到绳子 x）
- `call [vtable+0x14]`

**攀爬过程**（`0x9D7C11` → `0x9D80EC`）：
- y（`+0x38`）+= 3（常数 `0xB00D68`）× `+0x154`（上键 -1 / 下键 1）
- 夹在 y1、y2 之间

### 未解决

## 三种跳

### A 级（指令记录）

**陆跳**（有立足对象时）：
```
vy = -(decrypt([move+0x198]+0x48) × Physics[+0x70]) / decrypt([move+0x190]+0x24)
```
**下跳**：
```
vy = decrypt([move+0x190]+0x24) / (Physics[+0x70] × -0.35355339)
水平速度写成 0
```
- 加载函数 `0xA4D393`：`+0x70` = **jumpSpeed**（不是 gravityAcc；gravityAcc 在 +0x60）

### 常数归属（修订）
`0.3 / 0.5 / 1.3` 乘的是移动对象 `+0x150` = **水平键（-1/0/1）**分支，
不是水中跳参数。

### 未解决
- **水中跳：没有式子形状**（指令记录中无）
- `decrypt([move+0x190]+0x24)`、`decrypt([move+0x198]+0x48)` 的字段名

### C 级假设（不作结论）
- 反编译 `FUN_009BD0D9` 显示飞行/无立足分支乘 `swimSpeed(+0x48)×5.0` 并与
  陆跳共用 `ENC(-vy)` 写入尾——是否即水中跳**未经指令级证实**
- `FUN_0070DF65` 中 `move+400(0x190) != 0` 门控一个解密位置后的包含判定
  ——`+0x190` 的身份与其在跳跃公式中被解密使用的记录**存在张力，身份未定**
- 三张验证图无 SwimArea 矩形 → 全图水域走 `info.swim → field+0x150`
  （指令记录）；SwimArea 矩形装载器（`0x53602C`，B 级：与 WZ 四字段对照）
  服务的是局部水域。`field+0x150` 与移动对象 `+0x150`（水平键）**互不相干**
