# GLM Research Workspace Archive

这里保存历史 GLM / OpenCode 逆向研究会话的计划、状态、脚本、scratch 和阶段性产物。

- `reverse-engineering-plan.md`：研究路线图。
- `analysis/STATUS.md`：研究进度与未决问题。
- `result/`：该研究工作区形成的结构化结果。
- `scripts/`：工作区内形成的分析脚本。
- `scratch/`：历史调试和中间产物。

新研究会话的唯一写入范围由 `prompt.md` 规定，只能写入本目录。

## Scratch archive note

`scratch/` stores historical debugging scripts and intermediate outputs. It is an evidence archive, not a guaranteed runnable tool surface; older scripts may retain their original workspace assumptions. Before reusing one, verify its input/output paths and promote a corrected version into this directory or `research/scripts/`.
