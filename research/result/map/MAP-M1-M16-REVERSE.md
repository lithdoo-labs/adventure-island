# M1–M16 指令级逆向回答

日期: 2026-11-11。映像 `.work/task-036/game-image-unpacked.bin`，ImageBase `0x400000`，文件偏移 = VA − `0x400000`。
工具: Capstone 逐函数反汇编（`dis(VA)`），地址一律 VA。Ghidra 仅用于定位函数，不作为结论。
不重开清单、不重写的式子以 `MAP-MOTION-REVERSE.md`、`MAP-PHYSICS-CORRECTION.md`、`MAP-REVERSE-STATUS.md`、`MAP-CAMERA-REVERSE.md` 为准。

同一函数只反汇编一次，结果分填各条。加密读写跟着 `0x6131F4`（写）/ `0x6A0545`、`0x548806`（读）走。

## M1 松开下键之后，哪条指令改掉蹲下

**从哪看**: `0x9533EA` 第二参数最高字节带 `0x80` 的松开分支（`0x953570` 起）。

**指令**:
```
009534B4  test byte ptr [ebp+0xF], 0x80
009534B8  jne 0x953570            ; 松开分支
00953570–009535EA: call 0x75B1CC(全局,动作号,0)；左/右(0x25/0x27)方向时
  0x65D77F、0x96C957→0x94A09C→0x97AE26；尾部
009535E5  call 0x968550           ; 清 [user+0x2EE4]/[user+0x2EE8] 等
```

**写入**: 松开分支本体与尾调 `0x968550` 一层内，对 `prone`（十进制槽 33）或动作名表
（`0xBDDB10`）没有任何写入（立即数扫描 0x21/33 与表基址引用均为 0 命中）。
`0x952F1F` 的 `+0x158=1` 是起跳标志（不重开）。

**结论**: **没有这条写入**。松开路径不改蹲下动作。
**等级**: A。
**不重开**: `0x952F1F(+0x158)`；`0x9533EA` 按下分支按 `MAP-MOTION-REVERSE.md` 键位表。

## M2 脚落到立足线之后，身体动作写成哪一个名字

**从哪看**: 立足对象 `+0x110` 从 0 变非 0 的写入点及其一层调用。

**指令**:
```
; 位置设置器 0x9BC622（虚表 0xB0CC78+0x04）
009BC6CA  mov [ebx+0x114], edi        ; edi = 立足对象（参数）
009BC6E5  mov [ebx+0x110], edi        ; 仅当 [ebx+0x14]->虚表[0] 返回 7 时写
009BC715  call 0x9BC89F               ; 纯加密槽复制（只调 0x548806/0x6131F4/0xA70FBB）
009BC724  call 0x9BC992               ; 同上
; 分发器 0x9BCD6C 命中后只做位置重积分与快照，无动作引用
; 分发器调用的其余虚表方法 0x9BF1FA(+0x0C)、0x9BC4CC(+0x1C)、0x9BC4CD(+0x20)、
; 0x9BE703(+0x10)：动作表 0xBDDB10 / 字符串 0x7A48D0 / 立即数 33 全部 0 命中
```

**写入**: **没有这条写入**。落地链（`0x9BC622` → `0x9BC89F`/`0x9BC992`，分发器 `0x9BCD6C`
及其已调用虚表方法）没有任何动作名或动作下标写入。`0x9BCFF2` 读 `Jump` 是 `0x9BCFED`
速度路径、`0x95A31E` 动作号 2 是 `stand1` 且读全局 `+0x150`——均不重开为落地。

**等级**: A。
**已看函数**: `0x9BC622`、`0x9BC89F`、`0x9BC992`、`0x9BCD6C`、`0x9BF1FA`、`0x9BC4CC`、`0x9BC4CD`、`0x9BE703`。

## M3 `0x95516A` 坐下：sit 写入与座位下标清除

**指令**（一次反汇编，两条分填）:
```
00955254  mov ebx, eax               ; ebx = 0x54634C 座位查询下标
00955258  jl 0x9552AE                ; <0 即退出
0095525A  push 0x25 ; call 0x6F5E40  ; 报文头（字符串号 0x25，非动作槽）
00955268  push ebx ; call 0x4291B3   ; 下标追加进报文
0095527B  call 0x495C5C              ; 发报文
00955280  mov [edi+0x2088], 1        ; edi = [0xBD9028]（用户对象）
00955296  mov [edi+0x208C], eax      ; eax = 0x994C7A()（时间戳）
```

**写入（坐下）**: `0x95516A` 里**没有** `sit`（0x27/39）动作写入；它把座位下标写进**报文**，
本地只写 `field+0x2088 = 1`（已记录）与 `[user+0x208C] = 0x994C7A()`。
task050 另一对象的 `+0x2088` 是复位标志，不当 seatId。

**起来时的清除**（已调用层）:
```
; 座位换景/离开处理器（0x558579、0x55DAE2、0x57F13C，全映像 +0x2088 清零扫描）
005585A6  and dword ptr [edi+0x2088], 0     ; edi = [0xBD9028]
005585CA  mov [edi+0x208C], eax             ; eax = 0x994C7A()
```
再次进入 `0x95516A` 的各失败门（`0x9552BD` 立足/速度判定、`0x6A0ADF`）都不触碰 `+0x2088`。
人物身上的座位下标本身**从未本地保存**（只进报文），因此也没有可清的下标。

**结论**: 报文之前没有 sit 写入；本地标志 `+0x2088` 的清零只发生在换景处理器
（0x558579/0x55DAE2/0x57F13C），不是由左右移动或再次按键触发。
**等级**: A。

## M4 水中跳：速度槽、`info.swim` 拷贝、全局与地图字段、动作号

**指令**:
```
; 无立足分支 0x9BD367（一次反汇编，M4/M5/M6 分填）
009BD38E  call 0x70DF65              ; 水中/飞行判定
; --- 0x70DF65 本体 ---
0070DF6D  call 0x70DFC9              ; [move+0x190]->+0x30 虚表方法==1 → 飞行=1
0070DF76  cmp [edi+0x190], eax       ; +0x190 == 0 → 返回 0
0070DF7F  push [edi+0x48] ; lea eax,[edi+0x38] ; call 0x548806   ; 解密 y
0070DF91  push [esi+0x10] ; push esi(=+0x20)  ; call 0x548806   ; 解密 x
0070DFA0/0070DFA6  call 0xA70F94 ×2  ; 转整数
0070DFAB  mov ecx, [edi+0x190] ; add ecx, 0x3C
0070DFB5  call 0x5C8A56              ; 矩形包含判定（含 0x5C9EC7 二分）
; --- 回到跳 ---
009BD397  mov eax,[esi+0x198] ; lea ecx,[eax+0x6C] ; call 0x6A0545
009BD3AD  fmul qword [eax+0x48]      ; swimSpeed
009BD3B0  fmul qword [ebp-0x14]      ; 斜率（0xA70FBB 处理过的双精度）
009BD3B3  fmul qword [0xB04F40]      ; 5.0
009BD42D  lea ecx,[esi+0x68]
009BD430  fchs
009BD437  call 0x6131F4              ; 写 vy
009BD43C  mov [esi+0x78], eax        ; 校验
```

**回答**:
- **速度槽**: 该分支（`0x70DF65` 返回 1，即飞行或在矩形内）vy 写 **`+0x68`（校验 `+0x78`）**，
  与陆跳/下跳同槽。vx 不在这一支写（飞行子支 0x9BD3EB 才把 `+0x50` 加倍）。
- **`field+0x150` 有没有抄进移动对象**: **没有**。`info.swim` 在 `0x534CBE` 写进地图对象
  `[esi+0x150]`；移动对象 `+0x150` 是水平键（`0x9C4B78` 从键位写 `+0x150/+0x154`），全映像
  没有 field→move 的复制指令。`0x9BD0DE` 读的 `+0x150` 是水平键（不重开）。
- **全局 `[0xBDF54C]+0x150` 与地图字段是否同一份**: **没有找到关联**。全映像对 `0xBDF54C`
  只有读取（`mov eax/ecx,[0xBDF54C]`，含 `0x4376F2` 一族）与清零（0x77E9A5 一带、0x77FC75），
  **没有任何把地图对象存入 `0xBDF54C` 的写指令**（A1/A3/89/8B/C7 全模式扫描）。两份 `+0x150`
  无法判定为同一份。
- **水中播放的动作号**: **没有这条写入**。跳路径（0x9BD0D9/0x9BD367/0x9BD42D）无动作表引用。

**等级**: A（动作号 = 没有写入）。
**新结构证据**: `0x70DF65` 揭示 `[move+0x190]` 是一个多用途记录：`+0x18/+0x24` 为加密双精度
（跳跃公式项），`+0x30` 为飞行判定方法，`+0x3C` 为矩形容器（水中包含判定）。

## M5 四个 decrypt 旁的字段名

**从哪看**: `0x9BD20E`、`0x9BCFED`、`0x9BD42D` 旁边及 `[move+0x190]/[move+0x198]` 的写入者。

**等级**: A（否定式）。

## M6 行走、游泳、重力积分与时间量度；`+0x180/+0x188` 来源

**指令**（分发器 `0x9BCD6C` 一次反汇编，各分支分填）:
```
; --- 分发（0x9BCD6C）---
009BCD81  cmp [ebx+0x158], esi ; jne→0x9BD567（起跳清标志后进 0x9BD0D9）
009BCD95  cmp [ebx+0x178], esi ; jne→0x9BD58F（受迫位移修正）
009BCDA4  cmp [ebx+0x160], esi ; jne→0x9BCFED（下跳）
009BCDC2  cmp [ebx+0x110], esi ; 有立足→0x9BD757(爬)/0x9BE703(行走)；无→0x9BDF18(下落)
; --- 时间换算（0x9BCE11 与 0x9BDF92 同形）---
009BCE0E  fild dword ptr [ebp+8]
009BCE11  fmul qword ptr [0xAFECD0]      ; 常数 = 0.001 → 入参毫秒转秒
; --- 重力（下落 0x9BDF18）---
009BDF92  fild [ebp+8]; fmul [0xAFECD0]  ; dt
009BDFA3  ... 0x9BE096  fmul qword [ebx+0x60]   ; gravityAcc
009BDFC1  fmul qword [ebx+0x68]          ; fallSpeed 项
009BDF6E/0x9BDF8A  fmul qword [ebx+0x28]/[ebx+0x30]  ; walkDrag/floatDrag2 阻力项
; --- 行走（0x9BE703 尾部）---
009BEE0B  fld [edi+0x30] ; 斜率投影; 0x9BEE13 fmul [0xAFEC20](0.5) 梯形项; 写回 +0xE0 块
; --- 相邻两次调用的时间量度 ---
; 调用方 0x9C4B6D: push ebx（ebx=[esp+0x10] = 上层毫秒增量）; 无固定周期立即数
; 0x9C4B58: sub [esi+0x248], ebx; jns → 周期预算也在调用方累计，映像内无周期常数
```

**`+0x180/+0x188` 来源**（新解，全映像 `fstp qword [reg+0x180/0x188]` 扫描仅 6 处）:
```
; 0x7ACCFF(move, dx:double, dy:double) —— 受迫位移入口（pt13 调用，见 M16）
007ACD02  and [ecx+0x16C], 0
007ACD09  cmp [ecx+0x178], 0
007ACD18  fldz; 007ACD1A fstp [ecx+0x188]; 007ACD22 fstp [ecx+0x180]  ; 先清
007ACD2B  mov dword ptr [eax(=+0x178)], 1        ; 激活 0x9BD58F 修正
007ACD28–007ACD8E  dx 依 [ecx+0x180] 累加钳制 → fstp [ecx+0x180]
007ACD98–007ACDF8  dy 同理 → fstp [ecx+0x188]
```
`0x9BD58F` 把它们加进 `+0x50/+0x68` 速度槽（校验 `+0x60/+0x78`，已记录）后由分发清 `+0x178`。

**结论**: 行走=斜率投影 + 0.5 梯形项（0x9BE703）；重力/阻力=0x9BDF18 的 `gravityAcc(+0x60)`、
`fallSpeed(+0x68)`、`walkDrag(+0x28)`、`floatDrag2(+0x30)` 各乘 dt（毫秒×0.001）；
受迫位移 = `0x7ACCFF` 写 `+0x180/+0x188` 累加器。**周期: 映像内没有周期常数**——
分发入参是上层毫秒增量（×0.001 转秒），相邻间隔由调用方节拍决定，不在本映像。
**等级**: A。

## M7 绳子 `l` 选 ladder 还是 rope，并把动作名写到人物上

## M8 `+0x80`、`+0x98` 的名字与写入；空中抓绳是否用这一对

**指令**（0x9D7C90 起，一次反汇编）:
```
009D7CDB  push dword ptr [ebx+0xA8]     ; 校验字
009D7CE1  lea edi, [ebx+0x80]
009D7CEA  lea eax, [edi+0x18]           ; = +0x98
009D7CEE  call 0x548806                 ; 解密 +0x98 槽
009D7D13  push dword ptr [edi+0x10]     ; = +0x90 校验
```

**等级**: A。

## M11 `field+0x13C` bit 17 与立足线 `forbidFallDown` 是否同一位

**指令**（立足线加载 0xA4DDDB 内，一次反汇编）:
```
00A4E6F9  push 0x1161               ; 字符串号 = forbidFallDown
00A4E6FF  call 0x7A48D0             ; 字符串表取值
00A4E720  call 0x403AC7 ; 0xA4E72A call 0x415344
00A4E72F  neg eax; sbb eax,eax; neg eax    ; 收敛 0/1
00A4E735  mov [ebp-0x18], eax
00A4E961  cmp [ebp-0x18], ebx(0)
00A4E969  push [ebp-0x18]
00A4E96C  lea ecx, [eax+0x30]       ; eax = [ebp-0x58] = 立足线记录
00A4E96F  call 0x630025             ; 写进立足线记录 +0x30（经 0x630025）
```

**回答**: **不是同一位**。`forbidFallDown` 被收敛成 0/1 后经 `0x630025` 写**每条立足线记录
的 +0x30**，不写 `field+0x13C`。`field+0x13C` bit 17 的来源是地图 flags（值码"40"经
`0xAD6EA` 转换器），与立足线字段是两套存储。`0x95308C` 第一道门读的是 `field+0x13C` bit 17
（`0x5024C5` 返回 0 且该位为 1 才拦），不重写为下跳开关。
**等级**: A。

## M16 `pt` 7、8、9、11、12、13 各自写什么

**指令**（`0x954B58` 一次反汇编，哨兵分支 `tm==999999999` @ `0x954BFF`，及其后 pt 分派）:
```
; --- 哨兵分支 0x954CF3 ---
00954CF6  cmp eax,7 ; je 0x954D09
00954CFB  cmp eax,8 ; je 0x954D09
00954D00  cmp eax,0xB(11) ; jne 0x954E90        ; 只有 7/8/11 继续
00954D09  call 0x485138(user, 0x1F4, 0)          ; 门
00954D54  cmp ebx,0x5F5E164 / 00954D85 cmp ebx,0x363D7F80  ; 特例地图串
00954DB6  push 0x1293 → 0x490191(串, 0xB)        ; [user+0x35B0]>0 时的脚本支
00954DED  push 0x61 → 0x6F5E40                   ; 报文头（串号 0x61）
00954E03  mov al, [eax+0x12C]                    ; 地图字节
00954E20  add esi,4; push esi(pn) ; 0x418F94
00954E31–00954E53  追加当前 x/y（word）
00954E62  call 0x495C5C                          ; 发报文
00954E67  mov esi,[0xBD9028]
00954E6D  mov [esi+0x2088], 1                    ; ★ 座位标志（与 M3 同一对）
00954E80  mov [esi+0x208C], eax                  ; ★ 0x994C7A() 时间戳
; --- pt 分派（命中路径，0x9547FF 起）---
009547FF  cmp eax,0xC(12); jne → 00954804 call 0x9549DF   ; pt12 效果（记录：±200±100、-2300、VerticalJump）
00954810  cmp eax,0xD(13)                                  ; pt13:
00954826  call [全局+虚表+0x1C] → 结果 ∈ {19,20,21} 且立足非 0 时:
00954865  push 0x13(19); 00954869 call 0x53E95D(move, 19)  ; 状态命令 19
0095486E–00954897  fild −[esi+0x34] / [esi+0x38] → 0x7ACCFF(move, −门x, 门y)  ; 受迫位移（即 M6 的 +0x180/+0x188 写入者）
```

**回答**:
- **pt 7/8/11**（哨兵）: 过门后或走脚本支（串 0x1293→0x490191），或发报文（串 0x61 + 地图字节
  `+0x12C` + pn + 当前 x/y）并 **`[user+0x2088]=1`、`[user+0x208C]=时间戳`**——与坐下同一对标志。
- **pt 9**: 哨兵分支不匹配（0x954D00 无 9），落到 `0x954E90` 通用路径（已记录的
  `0x5CDE3F`/town 分流 `0x7C41E5`/`0x54744E`），**无 pt9 专属写入**。
- **pt 12**: `0x954806 → 0x9549DF`（效果函数：左右键、按朝向 ±200±100、常量 −2300、
  VerticalJump——记录在案，不接回人物下跳）。
- **pt 13**: `0x954810` 起——全局地图态虚表 `+0x1C` 返回 19/20/21 且立足非 0 时，
  `0x53E95D(move, 19)` + **`0x7ACCFF(move, −门.x, 门.y)`**（受迫位移，正是 M6 中
  `+0x180/+0x188` 的写入者）。

**等级**: A。四扇验证门（pt 1 或 3）的框不改。
**不重开**: pt12/13 的 VerticalJump 不接回 `0x95308C`。
