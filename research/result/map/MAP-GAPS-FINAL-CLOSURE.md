## 缺口 2/3：水中跳速度写入 — 已解决

**空中/跳跃处理器 0x5BD0D9（VA 0x9BD0D9）全解码**——三分支共用同一写入：

```c
if (状态查询() == 0) {                        // 非飞行
  vy = DEC(param) × flySpeed(+0x58) × slope;              // 飞行跳
} else if (双跳标志) {
  vy = flyJumpDec(+0x90) × flySpeed(+0x58) × param × 5.0; // 飞行跳衰减版
  if (再次跳) vy_2 = DEC(vy) × 0.7;                        // 二次跳 0.7
} else {
  vy = DEC(param) × swimSpeed(+0x48) × slope × 5.0;       // ★ 游泳跳分支 (0x9BD3AD)
}
ENC_WRITE(-vy) → move vy 槽 (+0x78);          // ★ 统一写入（所有分支共用）
// 陆跳在 0x9BD1FD: vy = -(A × jumpSpeed(+0x70)) / B → 同一写入
```

**结论**：水中跳速度写入一直存在——与陆跳共用 `ENC(-vy)→+0x78`。
旧记录"水中跳没有速度写入"是误读（分支汇合点在共享尾）。

## 缺口 1：swim 判定 — 全链闭环

**判定器 FUN_0070DF65（VA 0x70DF65）**：

```c
swim(move):
  if (fly模式检测()) return 1;                        // 飞行图恒真
  if (move+0x190 != 0) {                              // ★ SwimArea 矩形列表非空
    y = DEC(move+0x38/+0x48);  x = DEC(move+0x20/+0x30);   // 解密当前位置
    return FUN_005C8A56(x, y);                        // ★ 矩形包含判定
  }
  return 0;
```

**move+0x190（十进制 400）= SwimArea 矩形列表指针**——跳跃公式里
`decrypt([move+0x190]+0x24)` 的真身 = 解密矩形记录字段（几何，非 WZ 属性）。
[move+0x198] = 立足点指针（物理 tick 0x5BD757 line 47 证实）。

**包含判定 FUN_005C8A56**：排序坐标数组上的二分查找（FUN_005C9EC7 = lower_bound），
x/y 各自定位区间，组合判定落入哪个矩形。

**完整管线**：WZ swimArea 节点 → 装载器 0x53602C（读 x1/x2/y1/y2，
字符串号 0x82E/0x830/0x82F/0x831）→ 加密矩形记录（FUN_005488A6，0xBAADF00D 家族）
→ move+0x190 列表 → 每帧解密当前位置 + 二分包含 → swim 状态。
