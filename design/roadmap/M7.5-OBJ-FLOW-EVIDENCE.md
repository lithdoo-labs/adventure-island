# M7.5 Obj flow 本地动画 — 验证证据

> **里程碑状态：2026-11-21，M7.5 实验切片已在真实 `230030200`、`ms-map-object` 与 canonical PWA 中闭环。**
> **批准状态：组件 ABI、Obj flow 视差/完整 0x66A8D5 子实例语义、非 flow=1 模式、正式 FieldPlan ABI 仍未批准。**

## 1. 范围与证据边界

- **CMS079-PROVEN**：Obj `flow` 作为 `0x66A8D5` 的 mode 实参；bit0=水平重复、bit1=垂直重复；`flow=0` 单次迭代（C-049）。Obj 与 Back type1–4 共享平铺 helper，但 `rx` 不在该 helper 实参表中（G36-G37）。
- **PRODUCT-DECISION**：Obj 的 `rx` 不在已恢复的 `0x66A8D5` helper 实参中；本切片暂复用 M7.4 Back type4 的 `20000 / |rx|` 作为候选滚动钟，不宣称 CMS079 parity。
- **FSDB-FACT**：`230030200` 恰好 **11** 条 `flow:1` + 非零 `rx` 鱼群 Obj（sourceOrder 22–32）；均无 `cx/cy`；每条 **4** 帧 `delay` 来自 ObjFrame。
- **PRODUCT-DECISION**：在完整 `0x66A8D5` 子对象语义与 `+0x90/+0x98` 动态体未恢复前，每条 flow Obj 仍映射为 **一个** `ms-map-object` + 有界 viewport 宽度（1000px）局部 Canvas；水平平铺与 `rx` 滚动使用 **renderer-local presentation clock**；多帧序列使用 FSDB `delay` 循环；不写回 FieldState。
- **fail-closed**：`flow∉{1}`、`flow` 垂直位、`r≠0`、缺 `rx`、缺帧、资源/Canvas 超预算均保持 unsupported 或拒绝，不伪造首帧或单 Canvas 全场景。

## 2. 架构与失效边界

- 业务权威仍在 `adventure-map` Subsystem；`projectObjFlowCameraUpdates` 仅 patch `world-x/world-y`，与 M7.4 `projectBackCameraUpdates` 对称。
- `ms-map-object` 只持有自己的 Shadow DOM Canvas；`animationPaints` 计数局部重绘；`paintCommits` 仅在资源加载完成时增长。
- Camera-only `world-x/world-y` patch 不进入内容签名，不重复读取或解码帧；不同尺寸/原点的 Obj 帧按自身 source rect 与锚点合成，不拉伸到首帧尺寸。
- 全场景仍由多个 Paint Unit 组成；Obj flow 不重绘 `ms-map-back` / `ms-map-batch` / Tile 层。
- 异步解码在 `finally` 关闭 bitmap；epoch / 连接状态在 `await` 后复验（沿用 M3 carrier 语义）。
