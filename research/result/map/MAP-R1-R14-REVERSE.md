## R1 地面行走的世界坐标

**要看到的写入**: 立足对象非 0 时按住左右改世界坐标；松键后水平速度怎样变。

**从哪继续**: `0x9BE703` 尾部写进的 `+0xE0` 参数化块的消费者，及松键路径改水平速度的指令。

**指令**（分发 `0x9BCD6C` 有立足分支 + 虚表 `+0x0C` = `0x9BF1FA`，各一次反汇编）:
```
; 分发器有立足分支：把 +0xE0 块快照后调虚表 +0x0C：
009BCE1C  lea eax, [ebx+0xE0]; rep movsd → 局部
009BCE30  call 0x548806                  ; 解密 +0xE0 参数化位置
009BCE3F  call 0x548806                  ; 解密另一端
009BCE44  fmul qword ptr [ebp-0x10]      ; × dt（分发器已算好 [ebp-0x10] = 毫秒×0.001）
009BCE50  fadd qword ptr [ebp-8]         ; + 旧参数
009BCE5C  call 0x6131F4                  ; ★ 写回 +0xE0 参数化位置（校验 [esi+0x10]）
; 虚表 +0x0C = 0x9BF1FA（本函数）按参数化位置在立足线链上推进：
009BF2FB  call 0x548806                  ; 解密 +0xE0 位置
009BF315  fld qword ptr [ecx+0x40]       ; 立足线 +0x40 端点
009BF343/009BF34D  端点选取后:
009BF357  call 0x6131F4 → [esi+0x10]     ; 写 +0xE0
; 换线到尽头（速度方向上的下一条），把参数推到端点值:
009BF553  call 0x6131F4 → [esi+0x10]; 009BF565 call 0x6131F4 → [esi+0x28]
; 然后由世界坐标恢复函数把参数化块映射回 +0x20/+0x38:
009BF573  lea ecx, [ebx+0x20]; push esi(+0xE0); push [ebx+0x110]
009BF577  call 0x9BC992                  ; ★ 参数化 → 世界坐标（纯加密槽搬运，M2 已看）
; 空中分支同形（0x9BCF52..0x9BCFBD），区别只是无立足时的速度积分来源。
; 松键（水平键 = 0）在下落处理器里：
009BE0AD  mov esi, [esi+0x150]           ; 水平键
009BE0B8  jne 0x9BE163                   ; 按住 → 驱动支
009BE0BE..0x9BE13E  键==0：不加驱动，只按 dragK = walkSpeed/walkForce×dragTerm × dt 衰减
; 走地松键：0x9C4B78(+0x150/+0x154) 由上层写 0，行走/下落各自按上面处理。
```

**回答**: 有立足时世界坐标不直接由行走函数写——行走积分在 `+0xE0` 参数化块内
（`0x9BCE5C` 写入），再由 `0x9BF1FA` 末端 `0x9BF577 call 0x9BC992(move+0x20, +0xE0, 立足)`
从立足线几何恢复世界坐标对（`0x9BC992` 是纯加密槽运算，自身无独立公式输出明文）。
松键后水平速度在下落路径由 `dragK × dt` 衰减（0x9BE0BE 支），在行走路径由
`+0xE0` 参数对端点直接钳住（0x9BF357 一支写端点值）——**没有把速度清零的指令**。
速度槽、dt 均同 N2（`+0x50/+0x68` 对，dt=毫秒×0.001）。

**等级**: A。

## R2 空中水平速度的闭合式

**要看到的写入**: `0x9BE4CC`–`0x9BE5A8` 收成一条式子；按住/没按住两种结果。

**指令**（`0x9BDF18` 内 0x9BE0AD 起，一次反汇编）:
```
009BE0AD  mov esi, [esi+0x150]      ; key = 水平键 ∈ {-1,0,1}
009BE0B8  jne 0x9BE163              ; key≠0 → 驱动支
; —— key == 0 支（0x9BE0BE..0x9BE15E）——
009BE0F3  fld [ebp-0x30]; fmul [[物理]+0x38]   ; dragTerm × floatCoefficient(+0x38)
009BE10F/009BE13E  fdiv [ebp-0x20]; fmul [ebp-0x18]; fsubr/fadd [ebp-0x10]
            ; vx += ∓ (dragTerm/基准)×dt   （按 vx 符号向 0 逼近，钳在 0）
; —— key ≠ 0 驱动支（0x9BE163..0x9BE5A8）——
009BE3D3  call 0x70DF65             ; 游泳/飞行判定（见 R4）
009BE3E5  call 0x6A0545             ; DEC([move+0x198]+0x54) → L（游泳水平上限基数）
009BE3FB  fmul [[物理]+0x48]        ; × swimSpeed  → L·swimSpeed
009BE40B  call 0x6A0545             ; DEC([move+0x198]+0x78)
009BE41F  call 0x6A0545             ; DEC([move+0x198]+0x84)
009BE42C  fmul [[物理]+0x58]        ; × flySpeed（飞行支上限）
009BE42F  fmul [ebp-0x30]           ; × dragTerm → 上限（记为 Cap）
009BE448  fld [[物理]+0x40]         ; swimForce（0x70DF65≠0 时）
009BE44D  fld [[物理]+0x50]         ; flyForce（=0 支）
009BE45C  fild key                  ; 水平键
009BE45F  fmul 力                    ; × swimForce 或 flyForce
009BE462  fmul [ebp-0x48]           ; × dragK (= walkSpeed/walkForce × dragTerm)
009BE465  fmul [ebp-0x30]           ; × dragTerm → 驱动项 D = key·F·dragK·dragTerm
; —— 逼近（0x9BE47D..0x9BE5A8）——
009BE487  fld Cap; fdiv [ebp-0x20]; fmul [ebp-0x18]; fsubr [ebp-0x10]
            ; vx += (Cap/基准)×dt，钳在 ±Cap
; 0x9BE5C1/0x9BE5DF: key<0 乘 0xB05538(0.3)，key>0 乘 0xB06460(1.5) —— 只在 key≠0 支
```

**回答（闭合式）**:
```
基准 B    = DEC([move+0x198]+0x0C)
dragTerm  = DEC([move+0x190]+0x0C) × floatDrag2(+0x30)
dragK     = (walkSpeed(+0x08)/walkForce(+0x00)) × dragTerm

key == 0:  vx → 0，步进 vx += ∓ (dragTerm×floatCoefficient(+0x38)/B)×dt（带零钳制）
key ≠ 0:
  Cap = (0x70DF65≠0 ? DEC([move+0x198]+0x54)×swimSpeed : DEC(+0x78 或 +0x84)×flySpeed) × dragTerm
  D   = key × (0x70DF65≠0 ? swimForce(+0x40) : flyForce(+0x50)) × dragK × dragTerm
  D 本身先按 key 符号乘 0.3（负键）或 1.5（正键）
  vx → ±Cap，步进 vx += (Cap/B)×dt（带端点钳制）
```
`DEC([move+0x198]+0x54/+0x78/+0x84)` 的装载者：**没有**——与 N5 同因
（+0x190/+0x198 无静态写入者，`0x6131F4` 全调用点无一解引用这两个指针）。

**等级**: A（装载者 = 否定式）。

## R3 下落竖直速度的代入项

**要看到的写入**: decrypt 项与 `[esi+0x174]` 的装载者；命中门 `0x979AA8` 读什么。

**指令**（`0x979AA8` 一次反汇编）:
```
00979AAB  cmp [esi+0x110], 0 ; jne 返回0     ; 有立足 → 不进下落式
00979AB4  call 0x70DF65      ; jne 返回0     ; 游泳/飞行 → 不进
00979AC1  call [虚表+8]      ; jne 返回0     ; 第三态 → 不进
00979AC8  mov esi, [esi+0x198]; lea ecx,[esi+0x78]
00979AD1  call 0x6A0545      ; DEC([move+0x198]+0x78)
00979AD6  fcomp 0.0 ; ja 返回0
00979AE1  返回 1                         ; 命中态 = 无立足+非游+虚表8=0+DEC(+0x78)≤0
```

**回答**:
- **`0x979AA8` 读四个条件**: 立足 `+0x110`、`0x70DF65`（R4）、虚表 `+8`、`DEC([move+0x198]+0x78) ≤ 0`。全部通过才把 fallLimit 换成 `DEC(+0x24)×fallSpeed`。普通行走下落时若 `+0x110` 非 0，竖直路径整体跳过（`0x9BDF18` 只在无立足时被分发调用）。
- **decrypt 项装载者**: 没有（N5 已定，本次复核无新增）。
- **`[move+0x174]`**: 全映像 mod10 写 `[reg+0x174]` 扫描——移动对象区域无存储指令；它随整个状态由反序列化到达，静态无装载者。
式子保持 N2 的符号形式（fallLimit/dragTerm/dragK/基准），不约去基准，不写成 vy += g·dt。

**等级**: A（否定式）。

## R12 身体宽度、竖线、向上穿过

**要看到的写入**: 行走/下落时立足查询的半宽；x1==x2 竖线的拒绝比较；向上穿过的不停住比较。

**指令**（`0xA4F6F1` 头部一次反汇编 + 物理路径调用点）:
```
; 0xA4F6F1(x=[ebp+8], yLo=[ebp+0xC], out=[ebp+0x10], yHi=[ebp+0x14], halfW=[ebp+0x18]):
00A4F72E  mov eax, [ebp+0x18]          ; halfW（参数）
00A4F732  lea ebx, [edi+eax]           ; x + halfW
00A4F73A  sub edx, eax                 ; x − halfW
          ; → 查询区间 [x−halfW, x+halfW)
; 物理路径调用点（本次 + N 系一次反汇编）：
009CC1F8  push 1                       ; 0x9CC207（下落着地搜索）半宽 = 1
00977F42  push 1                       ; 0x977F52 半宽 = 1
00953236 一带（下跳）半宽 = 1（已记录）
; 竖线（x1==x2）拒绝：
00A4F778  cmp edx, esi ; jge skip      ; x2 < x1 → 跳过
00A4F77C  cmp edx, edi ; jg skip       ; x2 < xLo → 跳过（竖线在区间左侧）
00A4F780  cmp esi, edi ; jl skip       ; x1 ≥ xHi → 跳过（竖线在区间右侧）
          ; x1==x2 且在区间内：不跳过——
00A4F78A  sub eax, ebx (=0); imul eax, ebx; idiv esi(≠0)
          ; 除数 esi = x2−x1 = 0 时（x1==x2 且未跳过只在 x2==x1==区间端点边界）
```
实际竖线拒绝发生在**遍历源头**：立足线按 x1 升序进入树（`0xA4F759` 链表步进），
`x2 < x1` 的退化线在 `0xA4F778` 处被 `jge` 直接跳过——**x1==x2 的线不会作为墙挡住，
也不会命中**（除非零宽恰好贴边）。
**向上穿过**（脚点上移越过水平线）：`0xA4F6F1` 的区间测试只对
`[yLo, yHi)` 单向开（`0xA4F79B cmp eax, [ebp+0xC]; jl skip / cmp eax, [ebp+0x14]; jge skip`），
调用方（下落路径）传 `yHi = 当前y、yLo = 上一帧y`（R12 调用点回看 `0x9CC203`:
`edi = [eax+4] − 0xA`），向上时区间为空 → **任何比较都不满足，不停住**。

**回答**: 物理路径半宽全部是立即数 **1**（0x9CC1F8/0x977F42/下跳处）。
没有独立身体宽度字段。竖线被 `0xA4F778 jge`（x2<x1 退化跳过）与区间测试丢弃，
不当墙。向上不停住 = 查询区间单向开（`0xA4F79B/0xA4F7A0`）。

**等级**: A。

## R13 人物和 Obj 的前后

**要看到的写入**: 映像里函数体存在的第二比较器。

**扫描**: 排序键只进入虚表 `+0xB4`（0x666F7D，已记录）。人物渲染路径
（`cms-avatar-layer` 对应的 `0x8Fxxxx`–`0x93xxxx` 一族）没有第二个 comparator：
人物对象加入场景的路径调用的是同一张场景容器的插入方法（键 = `0x43715C` 一族的
层对象方法或人物 `y`），函数体同样运行时绑定。全映像范围内没有「比较两个键并返回
±1/0 的、函数体在本映像」的排序比较器与 0x666F7D 并存。

**回答**: **没有**。比较器唯一入口是虚表 `+0xB4`（调用点 0x666F7D），方法体不在
本映像。人物与 Obj 的先后由同一运行时比较器决定，静态不可判。

**等级**: A（否定式）。

## R14 调用周期、镜头、滚动节拍、换帧

**要看到的写入**: 传给 `0x9BCD6C` 的毫秒来源；镜头/滚动/帧号的函数体。

**指令**（8 个调用方一次反汇编）:
```
009C4B6A  push ebx; call 0x9BCD6C      ; ebx = [esp+0x10]（本函数参数，上层传入）
009C9DC2  push [ebp+8]; call …          ; 同：直接转发上层参数
009CC8F4  push [ebp+8]; …
009D01E5  push [ebp+8]; …
009D405D  push [ebp+8]; …               ; 0x9D409F/0x9D4314 同形
009D7C20  （第 8 处，同转发）
```
没有任何调用方压入立即数；毫秒全部是**上层参数的转发**。上一层的 `0x9C4B3C`
族把 `[esi+0x248]` 预算减去同一 ebx 后按符号分批——预算本身也来自更上层。
静态链止于 `ret 4` 的对象 tick 入口（`0x9C4B75`），毫秒值是游戏循环注入的参数。

**回答**:
- **毫秒来源**: 8 处全部 `push [ebp+8]` 或 `push ebx`（= 本层参数）。映像内没有周期立即数。
- **镜头跟随/dead zone**: 没有（MAP-CAMERA-REVERSE 全映像搜索，不重开）。
- **滚动节拍每步加几次**: 背景 `0x66A567` 的 `0x43715C` 返回值在滚动路径**加一次**
  `20000/|rate|`（0x66A576，单次 add，无循环）；符号由 `[ebp+8]`（水平标志）取负
  （0x66A582 `neg ebx`）。返回值单位未知（M15）。
- **换帧（背景/传送门）**: 没有——动画列表经虚表 `+0x110`（0x66A136）、pv 经
  `0x43286E`（0x71A983），方法体不在本映像（N7/N8 已定，不重开）。

**等级**: A（否定式 + 滚动单次加的指令）。
