# 逐函数阅读战役 — 第六批成果

日期: 2026-11-12。

## P1: UI 事件分派器 (mod10, 0x66fce0, 9.4KB)

37 个 case 标签，值域 0-7 → **8 种事件类型 × 37 个处理分支**。
Case 值 0-7 = 事件命令号（非索引）。这是一个**消息泵式事件处理器**：
- case 0: 基础事件
- case 1-3: 参数化事件（多个 switch 块处理不同子命令）
- case 4-7: 高级事件（技能/物品等）

结构 = **switch(subCmd) { switch(subSubCmd) { ... } }** 嵌套。

## P2: Gr2D 最大函数 (0x50024ae2, 35KB) — 变换矩阵计算

**不是主渲染循环**——是 **SIMD 变换矩阵运算函数**：
- `PackedFloatingADD` / `PackedFloatingMUL` = SSE 打包浮点运算
- 参数是 64 位 SIMD 向量（ulonglong*）
- 处理矩阵-向量乘法/加法 = **渲染管线的变换阶段**
- 无循环、无虚表 → 纯数学函数

**Gr2D 渲染管线组件**：
- 变换矩阵（35KB fn）
- Canvas 桥接（13KB, 98 callers）
- 初始化守卫（9KB, 'Already_initialized'）
- 其余函数经 COM/PCOM 间接调用

## P3: 攻击矩形建造器 B (0x563c7d, 14KB)

读取了函数头部——`DAT_00bdd838`（全局）+ `FUN_005caaa9`（方向查询）。
这是**方向感知的矩形建造器**：
- 输入方向（左/右）确定矩形的 x 偏移方向
- `DAT_00bdd838` 可能是攻击类别的默认范围

## 修正

mod10 的 "38 switches" 实际是 37 个 case 标签分布在多个 switch 块——
这是**嵌套 switch 命令分派**（非 38 个独立事件）。
