## 2. 内容身份与 RopePlan

- **FSDB-FACT**：`222000001` 发布一条绳记录：`x=-51,y1=-499,y2=474,l=0,uf=0,page=4,id=1`；内容版本为 `sha256:f47730e66772c107b00c4b7ff973d4a457f8406ffec8c9df98122e169f669dfb`。
- `ropeCollisionPlan` 是 FieldPlan 内的渲染无关碰撞索引，段数上限 64；`SOURCE-PRESENT` 必须携带严格 SHA-256 `contentVersion`，`SOURCE-ABSENT` 必须是 `contentVersion=null` 与零段，`SOURCE-EMPTY` fail-closed。
- RopePlan 自身对 `formatVersion/groupStatus/source/segments` 计算 SHA-256；构建时立即复核，测试覆盖篡改、非法内容身份与数量超限。
- 三图语义保持显式：`222000000` 与 `222000001` 为 `SOURCE-PRESENT`；`230030200` 为 `SOURCE-ABSENT`，不能把 absent 偷换成来源中的空数组。

## 3. Movement 权威与逆向约束

- **CMS079-PROVEN C-056/C-072**：攀爬每个 20 ms 业务 tick 沿垂直轴移动 3 px，端点使用已修正的 top/bottom 语义。
- **C-069/C-071/C-091**：命中带使用绳 x 的 `±10 px` 横向带；Down 查询脚上方 20 px，Up 查询脚下方 10 px；Up+Down 相消；抓取后速度归零并吸附到绳 x。
- **C-070/C-078/C-079/C-080**：Foothold 与 Rope 接触仍是 Subsystem 的 Movement context，不由 DOM/Canvas 反推；Rope 字段与加载记录保持来源身份。
- **C-081/C-090**：这两项闭合的是更广义的 user stand-up/到达触发链，并不单独证明 Rope exit；M7.3 只把它们作为 Movement context 清理边界，离绳后的站立/下落与换图仍由 Subsystem 决定，不把其细节冒充 CMS079 等价实现。
- **PRODUCT-DECISION**：B 的 sea00 支撑面比真实绳底低 40 px，允许 Down 抓取只桥接这一精确 authored gap；超过 40 px 拒绝，防止把抓绳变成无界传送。
- **PRODUCT-DECISION**：从绳底 Down 抓取时先保持接触，必须释放或反向一次才允许继续向下离绳，避免同一持续按键在下一个 tick 立即撤销抓取。
- 在攀爬态中，Controls 的 Up state 是攀爬轴；匹配的 Up event 不再被重新解释为陆地 jump。Portal 判定仍先执行，因此进入 `out00` 触发带后的新 Up 边沿可以提交 B→A。

## 4. 纸娃娃投影

- `cms-actor` 从真实 FSDB body `rope` 两帧生成循环动作，帧时长为 `[250,250] ms`；`locomotionActions.climb=rope`。
- `showFace=false` 只隐藏表情层，不等于 body-only：头、头发、帽/衣/裤/鞋/手套等存在精确 rope 行的部件继续按锚点和 z-order 合成；缺少精确 rope 行的武器/盾牌不伪造回退。
- 只有 Canvas 遮挡 tag 非空时才同时发布 `priority/tag`，避免空 tag 进入候选 ABI。
- 左右方向仍由 `facing` 投影；动作帧、锚点、部件顺序与镜像只在 Avatar 局部 Canvas 内更新。

## 5. 生命周期与失效边界

- Chromium 断言攀爬期间 Avatar `paintRounds` 增长，而 `ms-map-back/ms-map-batch/ms-map-object/ms-portal-visual` 的 `paintCommits` 完全不变。
- 独立审查发现 `ms-map-back` 在 `createImageBitmap` 完成后缺少第二次 epoch/连接状态检查，可能让退役载体重新获得非零 Canvas。现已在解码后及提交前复核 epoch 与 `isConnected`，并在 `finally` 关闭 bitmap、释放 controller。
- `carrier-lifecycle.test.mjs` 现在用延迟 Back 资源直接复现该窗口，要求断连 Canvas 宽度为 0、无迟到 paint、无资源读取泄漏。
