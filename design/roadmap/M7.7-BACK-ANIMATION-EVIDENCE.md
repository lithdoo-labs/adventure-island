# M7.7 Back `ani` 有界动画 — 验证证据

> **里程碑状态：2026-11-21，M7.7 实验切片已在真实 `230030200`、13 图 FSDB 范围、`ms-map-back` 与 canonical PWA 路径上闭环。**
> **批准状态：组件 ABI、delay 单位与 CMS079 帧时钟 parity、`+0x98` 视差、type5–7、正式 FieldPlan ABI 仍未批准。**

## 1. 范围与证据边界

- **FSDB-FACT**：13 图 Back 共 387 条 placement，仅 type 0–4；`ani=1` 的 200 条在 type 0–4 内；type 5–7 为零；`230030200` 有 21 条带动画帧的 Back。
- **CMS079-VERIFIED**：`ani` 为真时使用 `BackFrame` 的 `ani` 分支；帧按 `frame` 序号排序。FSDB `delay` 原样保留；缺失值投影为 `null`，不伪造为 `0` 或猜测默认时长。
- **PRODUCT-DECISION**：序列存在正 `delay` 时，帧推进采用 renderer-local `requestAnimationFrame` + 累计 `delay` 取模循环（与 M7.5 Obj flow 同一时钟形态）；`null`/`0` 不获得虚构驻留时间，全帧无正 timing 的序列保守停在首帧。不把 phase 写回 Subsystem；未宣称 CMS079 COM 帧时钟 parity。
- type 0–4 的静态布局/滚动（M7.4）与 type5–7、parallax `+0x98` 继续显式缺口。

## 2. 架构与失效边界

- Adapter `resolveMapScene` 对 `ani=1` 解析有序 `BackFrame` 全帧闭包；`projectBack` 对多帧发布 `mode: local-animation` + `frames[]`，单帧保持既有 `image/draw` 形状。
- Adapter 按所有帧的尺寸、origin 与 flip 计算稳定合成包络，并为每帧发布包络内 offset；宿主位置对应同一个 authored placement anchor。
- `ms-map-back` 在一个固定尺寸的宿主局部 Canvas 上组合 delay 帧时钟与 type4 滚动时钟；换帧不重分配 Canvas，不改变宿主框，不触碰静态地图层。camera/resize 只走 attrs/layout 失效，ready 后不重复 Content 读取。
- 动画帧 closure 计入 FieldPlan/adapter 资源边界；`pageWidth/pageHeight` 仍描述真实 Content 页，不得用 layout surface 冒充。
- epoch/retire/disconnect 中止在途帧加载，stale bitmap 在 `finally` 关闭；不引入 scene-wide Canvas。
